# User Stories & Acceptance

## Context
Our website helps older people shop online without getting confused.

## Content
### 1. Search
As a shopper, I want to find products easily.
- Given a product name, when I search, then matching products appear.
- Given no matches, when I search, then I see “No products found”.

### 2. Product details
As a shopper, I want clear product information.
- Given a product, when I open it, then I see its name, picture, price, and description.
- Given a description, when I read it, then the words are easy to understand.

### 3. Mobile buttons
As a mobile user, I want large buttons.
- Given a mobile screen, when I browse, then the buttons are easy to tap.
- Given items to buy, when I review checkout, then I see the total price.

### 4. Returns
As a shopper, I want to return items easily.
- Given an item to buy, when I check its details, then I can find the return policy.
- Given a purchased item, when I start a return, then I see simple instructions.

### 5. Confirmation
As a shopper, I want to know my order went through.
- Given a successful order, when checkout finishes, then I see “Order confirmed”.
- Given a confirmed order, when I view it, then I see the order number, items, and delivery information.
